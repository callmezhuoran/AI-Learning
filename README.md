## 使用方式

1. 每次开始读 `AGENTS.md` 和 `STATE.md`，再读当前课程与最近日志。
2. 用户提交代码、解释或结果后，在日志记录证据与反馈，同时更新 `STATE.md`。
3. 每天 09:00（Asia/Shanghai）的既有学习任务先读这些文件，再给出不超过 120 分钟的任务。
4. 无新反馈时安排当前课程续做，不自动标记完成、不堆积欠账。
5. 换一个聊天或工具时，提供本仓库并要求从 `AGENTS.md` 和 `STATE.md` 恢复。私有仓库需要访问权限。
